## 1. 产品说明

Haven 是一款离线优先的个人文件加密与隐私管理桌面应用。文件在导入时逐块加密写入本地保险库，界面上只展示元数据；数据保存在本机，不上传、不同步、无需联网。

当前版本仅提供 **macOS Apple Silicon（arm64）内部测试版**，未提供 Intel / Universal 架构，也未提供其他操作系统版本。

## 2. 安装包状态

- 当前 DMG **未使用 Developer ID 签名，也未经过 Apple 公证**。
- 签名检查结果：`codesign --verify --deep --strict` 失败，`spctl` 拒绝；应用仍可在本机受控启动并完成全部功能。
- 带 quarantine 属性（例如经浏览器下载）的当前安装包**可能被 Gatekeeper 拒绝运行**，不能保证所有用户下载后双击即可打开。
- 内测安装方式：确认文件来源可信后，在访达中右键点击 `Haven.app` 选择「打开」，或在「系统设置 → 隐私与安全性」中允许本次打开。
- 不得通过关闭系统完整性保护或全局 Gatekeeper 来绕过限制。

> 正式发布前将补 Developer ID 签名与 Apple 公证；本轮不处理签名与公证。

## 3. 基本使用

### 创建保险库与设置主密码

1. 启动应用，点击「创建保险库」。
2. 点击「选择位置」，选择一个父目录；Haven 会在其中创建固定名称的「我的保险库」的子目录。
3. 输入至少 12 个字符的主密码并再次确认，勾选「我已了解：忘记主密码将无法恢复任何文件」。
4. 点击「创建保险库」。创建完成后直接进入已解锁状态。

### 导入文件

- 点击「导入文件」选择一个或多个文件，点击「导入文件夹」递归导入其中的普通文件，也可以把文件拖入窗口。
- 导入为逐块加密写入，原文件保留在原位置，不会自动删除。
- 导入结束后显示成功与失败数量。

### 搜索、预览与整理

- 搜索框按文件名筛选；支持列表与网格视图、收藏、文件夹、重命名、删除、查看详情与完整性校验。
- 图片（JPG/PNG，≤20 MB）、PDF（≤20 MB）、视频（MP4/MOV/M4V/WebM，≤64 MB）可在内存中解密预览，不落地明文临时文件。
- 超出大小限制或类型不支持时，界面会提示不支持预览，不会伪造预览内容。

### 导出

- 支持单文件导出、批量导出和文件夹导出。
- **导出的文件是未加密副本，离开 Haven 后不再受 Haven 保护**；界面会显示「未加密副本」警告。
- 请自行妥善保管导出文件，必要时使用系统或第三方工具另行加密。

### 备份与恢复

1. 「备份保险库」：选择目标目录，Haven 复制当前保险库的加密文件，备份保持加密状态。
2. 「恢复保险库」或锁定页「从备份恢复」：选择备份目录 → 输入创建该备份时的主密码完成验证 → 选择恢复位置。
3. 恢复会在新位置创建「我的保险库」，不会覆盖原有保险库；恢复后用原主密码解锁即可。

### 锁定与退出

- 点击「锁定保险库」立即清理后端主密钥并回到锁定页。
- 连续 5 分钟无界面操作会自动锁定；导入、导出、预览等长任务不会暂停计时。
- 关闭窗口即退出应用；再次启动时仍为锁定状态，需要重新输入主密码。

## 4. 限制与安全边界

1. **主密码遗失无法找回**：Haven 不保存主密码，也不提供找回或重置；忘记主密码将无法解密保险库内任何内容。
2. **删除文件不等于安全擦除**：删除只移除保险库内的加密数据，不承诺覆写磁盘或清除文件系统、系统备份、存储设备层面的残留。
3. **不承诺清除系统级明文痕迹**：包括操作系统交换空间、休眠镜像、崩溃转储、系统日志、Spotlight 与缩略图缓存、其他应用的预览缓存等。
4. **当前不支持网络卷保险库**：请将保险库放在本机磁盘或本地外置磁盘，不要放在 SMB/AFP/NFS 等网络卷上。
5. **外置磁盘拔出不是实时监听**：拔出后 Haven 不会立即感知；下一次保险库操作才会触发挂载检查并失败关闭，会话进入不可用状态。需重新连接磁盘并重新输入主密码。
6. **休眠或系统锁屏不会让 Haven 立即自动锁定**：自动锁定只由应用内 5 分钟无操作计时触发，系统层面的休眠/锁屏不等同于 Haven 已锁定。
7. 不提供错误次数锁定；离线暴力破解的主要防线是 Argon2id 的计算成本。
8. 预览与导出会把明文短暂放入应用内存；应用无法保证清除操作系统管理的交换空间、崩溃转储或调试器捕获的内存。

## 5. 测试范围与已知限制

本轮最终安装包冒烟测试覆盖（macOS 26.5 / Apple M2 Pro / arm64，隔离临时 HOME 与临时保险库）：

1. 创建保险库
2. 导入 5 个测试文件（PNG/JPG/MP4/TXT/超长中文名）
3. 文件名搜索
4. 图片预览
5. 单文件导出（含未加密副本警告）
6. 批量导出（含未加密副本警告）
7. 备份保险库
8. 从备份恢复
9. 恢复后文件数量与内容核对（导出哈希与源文件一致）
10. 锁定保险库
11. 正常退出
12. 重启后仍为锁定状态
