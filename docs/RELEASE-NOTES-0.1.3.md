## 本次新增

### 主题中心（Theme Center）

新增独立「主题中心」功能，主题系统与保险库、加密、密钥完全隔离。

- 在已解锁界面新增「外观」入口，打开独立的主题管理弹窗。
- 内置 6 套主题：**Haven Original**（默认回退）、**Snow**、**Midnight**、**Forest**、**Sand**、**Lavender**；深色主题完整适配。
- 支持导入 `.haventheme`（UTF-8 JSON，≤256 KB）自定义主题，**Rust 侧唯一权威校验**：
  校验格式/版本/ID/名称/颜色/圆角，拒绝未知字段、脚本、HTML/CSS/JS 与外部资源引用；
  重复 ID 弹出覆盖确认，不静默覆盖；错误原因明确。
- 导入后先**预览**（背景、卡片、按钮、输入框、文件列表、选中态、成功/警告/错误提示、弹窗），
  预览不改变当前主题，点击「应用」才正式切换，取消即恢复。
- 应用即时全局生效，**无需重启**，不影响保险库锁定状态或进行中的文件操作，**不修改加密数据**。
- 「我的主题」支持查看、预览、应用、删除；内置主题不可删除，当前使用的主题不可直接删除。
- 主题偏好持久化在本地应用配置目录，自定义主题独立存放，与保险库数据分离；
  主题文件缺失/损坏或配置损坏时**自动回退 Haven Original**，不影响应用启动。
- 统一通过 CSS Variables 与 Naive UI theme overrides 管理颜色与圆角，无大规模 UI 重写。

### 项目官网

新增 Haven 静态产品官网（独立子目录 `haven-website/`）：

- 纯 HTML + CSS + 原生 JS，无构建步骤，已部署为公开 StaticWeb。
- 中英文双语，10 张真实产品截图，响应式桌面/平板/手机。
- 覆盖 Hero、功能介绍、安全设计、开源贡献、下载说明、FAQ。
- 官网地址：https://37lur66wyyzfjjex5tg.traesite.cn/

**未改动**：加密算法、密钥管理、保险库数据格式、CSP 与 Tauri 权限配置。

## 安装说明

1. 从 https://github.com/xan-ok/haven/releases/tag/v0.1.3 下载 `Haven_0.1.3_aarch64.dmg`。
2. **校验 SHA-256**（重要）：
   ```bash
   shasum -a 256 Haven_0.1.3_aarch64.dmg
   # 必须输出：d7e0e15873b9091253b1eeb5276f88a001b525fd324a97f205af932e65f3ba6f
   ```
3. 打开 DMG，将 `Haven.app` 拖入「应用程序」。
4. 当前包**未签名、未公证**。首次打开时系统提示「无法验证开发者」。
   在访达中右键点击 `Haven.app` → 选择「打开」→ 确认打开。
5. **不要关闭系统完整性保护（SIP）或全局 Gatekeeper**。

## 签名/公证状态说明

构建机上 **没有安装 Developer ID Application 证书**，也**没有配置 notarytool 凭据**，因此：

- 当前 DMG 未使用 Apple Developer ID 签名。
- 当前 DMG 未经过 Apple 公证。
- Gatekeeper 首次打开会拒绝，用户需要手动允许。

**这是当前构建环境的诚实状态**。当 Developer 证书和公证凭据配置完成后，后续版本将补全签名、公证和 Staple，并在 Release 中更新状态。

## 已知限制

| 类别 | 限制 |
|---|---|
| 签名/公证 | 未完成（构建机缺少证书与凭据） |
| 平台 | 仅 macOS Apple Silicon；Intel / Universal / Windows / Linux 不支持 |
| 密码 | 无法找回或重置；忘记 = 数据丢失 |
| 删除 | 不等于安全擦除；不承诺覆写磁盘或清除系统级痕迹 |
| 网络卷 | 不支持保险库放在 SMB/AFP/NFS 等网络卷 |
| 拔盘 | 不会实时监听；下次操作时触发失败关闭 |
| 自动锁定 | 仅由 5 分钟无操作触发；锁屏/休眠不会立即锁定 |
| 错误次数 | 无锁定；离线暴力破解防线是 Argon2id 计算成本 |
| 回收站 | 未实现 |
| 云同步 | 未实现、不计划支持 |
| 视频预览 | GUI 未做实测（无视频夹具），单元测试全部通过 |

## 升级注意事项

- **从 0.1.0 / 0.1.1 / 0.1.2 升级**：直接安装新 DMG 即可，旧保险库数据格式兼容，无需迁移。
- **安装包替换**：安装新版本会覆盖旧版本 App，保险库数据不受影响（保存在独立目录）。
- **主题数据**：主题偏好和自定义主题保存在应用配置目录，与保险库数据分离，版本升级不会清除。

## 安全说明

- 加密参数未变动：Argon2id 256 MiB / 5 次迭代，XChaCha20-Poly1305 AEAD，HKDF-SHA256 密钥扩展。
- 主题系统独立于加密和密钥管理：主题偏好保存在应用配置目录（`~/Library/Application Support/app.haven.desktop/themes/`），自定义主题格式由 Rust 侧校验，拒绝脚本、HTML/CSS/JS 和外部资源引用。
- CSP 和 Tauri capability 权限未改动。
- 前端纯浏览器构建，**无 Vite/Node 依赖运行时**，构建后产物为纯 HTML+CSS+JS。
