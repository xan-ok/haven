# Haven 0.1.3 发布说明（内部测试版）

- 版本：0.1.3
- 平台：macOS Apple Silicon（arm64）
- 产物：源码标签 `v0.1.3`（DMG 安装包待后续构建发布）
- 基线：v0.1.2（`24e2410aa1975b29285b2f0b91e7bfd95e6f7865`）

## 本次变更

新增独立「主题中心」功能，用于验证 Haven 的主题系统设计与实现，与保险库、加密、密钥完全隔离。

- 在设置区域新增「外观」入口，打开独立的主题管理弹窗。
- 内置 6 套主题：Haven Original（默认回退）、Snow、Midnight、Forest、Sand、Lavender；深色主题完整适配。
- 支持导入 `.haventheme`（UTF-8 JSON，≤256 KB）自定义主题，Rust 侧唯一权威校验：
  校验格式/版本/ID/名称/颜色/圆角，拒绝未知字段、脚本、HTML/CSS/JS 与外部资源引用；
  重复 ID 弹出覆盖确认，不静默覆盖；错误原因明确。
- 导入后先预览（背景、卡片、按钮、输入框、文件列表、选中态、成功/警告/错误提示、弹窗），
  预览不改变当前主题，点击「应用」才正式切换，取消即恢复。
- 应用即时全局生效，无需重启，不影响保险库锁定状态或进行中的文件操作，不修改加密数据。
- 「我的主题」支持查看、预览、应用、删除；内置主题不可删除，当前使用的主题不可直接删除。
- 主题偏好持久化在本地应用配置目录，自定义主题独立存放，与保险库数据分离；
  主题文件缺失/损坏或配置损坏时自动回退 Haven Original，不影响应用启动。
- 统一通过 CSS Variables 与 Naive UI theme overrides 管理颜色与圆角，无大规模 UI 重写。

未改动加密算法、密钥管理、保险库数据格式、CSP 与 Tauri 权限配置。

## 验证

在隔离 HOME、临时保险库中完成 GUI 验收（未使用真实保险库）：

1. 6 套内置主题均可显示并即时切换，Haven Original 与原版视觉一致，深色主题各页面适配。
2. 自定义主题导入、预览、应用、删除闭环通过；重启后保持已选主题。
3. 内置主题不可删除；当前使用的自定义主题删除按钮禁用并提示。
4. 异常输入（非法 JSON、缺字段、错误颜色、不支持版本、超限、脚本/外链、文件损坏、配置损坏）
   均给出明确提示并自动回退，应用可正常启动。
5. 业务回归：创建/解锁/锁定保险库、文件列表、PNG/PDF 预览、导入、导出（与原始文件 SHA-256 一致）、
   备份、恢复到新位置均通过；主题切换不影响进行中的业务操作。
6. 视频预览未做 GUI 实测（无视频夹具），现有视频加载单元测试全部通过。

前端 158 项测试通过；主题专项 8 项通过；Rust 265 项通过（主题存储 10 项）；

## 安装包状态

- 0.1.3 安装包尚未构建发布；当前可用的最新安装包为 0.1.2。

- 安全限制同 [0.1.0 发布说明](RELEASE-NOTES-0.1.0.md)：主密码无法找回、删除不等于安全擦除、
