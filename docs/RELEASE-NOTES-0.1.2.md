# Haven 0.1.2 发布说明（内部测试版）

- 版本：0.1.2
- 平台：macOS Apple Silicon（arm64）
- 产物：`Haven_0.1.2_aarch64.dmg`
- DMG SHA-256：`9ab7698616afbdeb1476df0c2668ccb89a9658703554a8e7b4c2bbd8a6745637`
- 基线：v0.1.1（`76e5dbda5ca169dca9091abcd4f86b8dc7876da1`）

## 本次变更

- 已解锁界面改为占满窗口高度：文件列表/网格占用剩余空间，不再固定为 280px 上限。
- 顶部信息压缩：移除重复的「我的保险库」小标题与独立路径行（路径改为标题悬停提示），
  文件夹标题行合并为一行标签，「全部文件 N 个」统计与批量选择栏合并同一行。
- 底部操作按钮保持单行并始终可见；导入提示改为「导入文件」按钮的悬停说明。
- 修复窗口高度不足时内容无法向下滚动的问题：内容较矮时整体居中，超出窗口时自动贴顶并可滚动。
- 修复网格模式下卡片被纵向压扁、只显示复选框的问题（固定 `grid-auto-rows`）。

未改动加密逻辑、保险库格式、会话状态机或 Tauri 权限配置。

## 验证

在隔离 HOME、临时保险库（25 个测试文件）中验证：

1. 1000×700 窗口：列表显示约 6 行并可滚动，底部操作按钮完整可见。
2. 1000×600 窗口：列表相应收缩，仍可滚动，操作按钮可见。
3. 网格模式：卡片完整显示缩略图占位、文件名与操作，可纵向滚动。
4. 窗口内容超出时页面可滚动（外层容器不再因居中裁切顶部）。

截图与记录：[docs/acceptance/20261125-layout-fix/](acceptance/20261125-layout-fix/)

前端 150 项测试通过；`cargo fmt --check`、`cargo clippy --all-targets -- -D warnings` 通过。

## 安装包状态

- 未使用 Developer ID 签名，未经过 Apple 公证；带 quarantine 属性时 Gatekeeper 可能拒绝运行。
- 安全限制同 [0.1.0 发布说明](RELEASE-NOTES-0.1.0.md)：主密码无法找回、删除不等于安全擦除、
  不承诺清除系统级明文痕迹、不支持网络卷保险库、拔盘非实时监听、休眠/锁屏不立即锁定。
