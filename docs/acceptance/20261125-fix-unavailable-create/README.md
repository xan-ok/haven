# 0.1.1「保险库不可用页创建入口」验证记录

- 版本：0.1.1（arm64）
- 验证日期：2026-11-25
- 环境：macOS 26.5 / Apple M2 Pro，隔离临时 HOME 与临时目录
- 场景：位置记忆指向一个存在但为空的目录（模拟原保险库数据丢失）

## 验证步骤与结果

1. 启动后进入「保险库不可用」页，显示路径与「该目录中没有找到 Haven 保险库数据」。
   - 页面提供「创建新保险库」「重新选择位置」「重试」三个按钮。
2. 点击「创建新保险库」，选择新的父目录，输入测试主密码并确认，勾选已知悉。
3. 创建成功，自动进入已解锁界面，页脚显示 `v0.1.1`。
4. 新保险库目录生成 `vault.json` 与 `index.hvn`。

结果：通过。
